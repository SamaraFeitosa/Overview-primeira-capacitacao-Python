# INTRODUÇÃO
Este projeto contém questões respondidas em python, onde foram abordados os seguintes temas: Tratamento de Dados, Análise e Correções, Visualização de Dados e Storytelling.

## 🛠️ ETAPAS REALIZADAS 
**Limpeza e Padronização:** Tratamento de colunas categóricas, correção de inconsistências de texto e recuperação de valores numéricos ausentes (`NaN`). 
 **Análise Exploratória:** Criação de tabelas dinâmicas (`pivot_table`) e filtragem de vendas de alto valor (Vendas VIP). 
**Visualização de Dados:** Construção de gráficos de linha, barras horizontais, boxplots e mapas de calor (*heatmaps*). 

## 💻 TECNOLOGIAS UTILIZADAS

- **Linguagem principal do projeto:** Python
- **Manipulação, limpeza e agregação dos dados:** Pandas
- **Computação numérica e operações matemáticas:** NumPy
- **Criação dos gráficos estatísticos:** Matplotlib & Seaborn
- **Ambiente de desenvolvimento interativo:** VS Code



## 🚀 COMO EXECUTAR O PROJETO
1. Clone este repositório ou baixe os arquivos para uma pasta local. 
2. Instale as bibliotecas necessárias:
   
    ```bash pip install pandas openpyxl matplotlib seaborn ```

4. Abra o notebook `.ipynb` no VS Code ou Jupyter e execute todas as células.


## 📖 MINHAS CONCLUSÔES

   Nas primeiras aulas do projeto (1, 2 e 3), foi abordado o tratamento da planilha Campe Supply. Com a orientação do Ítalo, fui capaz de analisar células vazias, resolver erros de ortografia e tratar dados duplicados. Nessa primeira etapa, os dados foram tratados e refinados, filtrando assim somente o que era ideal para a visualização de resultados.
   
   Nas aulas finais (4 e 5), após o tratamento de dados, pudemos trabalhar com eles. Agora, os dados apontam informações que antes não eram enxergadas. Os dados agora contam uma história. Com os gráficos, foi mostrado o que estava ali em linhas e colunas.
   
   Com o gráfico de linha, podemos ver os picos; colocando de forma estratégica nos eixos os campos de “mês” e “faturamento”, é possível observar os meses de maiores lucros.
   
   Com o gráfico de barras horizontais (particularmente um dos que mais gostei), é possível analisar os dados visualizando em cada barra o valor exato que ela representa — ideal para visualizar a quantidade de vendas e lucros e relacioná-los a alguma outra variável, como o vendedor ou a loja.
   
   O gráfico boxplot trouxe para mim uma perspectiva diferente, porém importante para identificar a dispersão dos dados, a mediana e a presença de valores irregulares nos setores.
   
   Já o gráfico Heatmap é o tipo de visualização que, ao bater o olho, chama imediatamente a atenção para os dados, permitindo identificar rapidamente, através das cores, onde estão concentrados os maiores e menores faturamentos por estado e cliente.

   Com o Storytelling vemos que é possível contar o que os dados mostram: Faturamentos em determinada época apontando para um lucro sazonal, lojas com menos vendas que podem esta recebendo novos investimentos, assim com as com mais vendas que podem esta recebendo novas filiais, vendedores com menos lucros que podem estar sendo ouvidos. Observando a repetição e os padrões é possível analisar o passado e escrever o futuro.
